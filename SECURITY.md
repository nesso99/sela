# Security Policy

## Supported versions

Sela is pre-release. Only the `main` branch receives security fixes.

| Version | Supported |
| --- | --- |
| `main` (pre-release) | Yes |
| Tagged releases | Not yet (no stable release) |

## Reporting a vulnerability

Please report vulnerabilities **privately** through [GitHub Security Advisories](https://github.com/nesso99/sela/security/advisories/new) (the repository’s **Report a vulnerability** link). Do not open a public issue for security bugs.

Include as much of the following as you can:

- A clear description of the issue and its impact
- Steps to reproduce, or a proof of concept
- Affected commit, branch, or package version
- Your suggested fix, if you have one
- Whether you plan to disclose publicly, and on what timeline

We will acknowledge the report and work with you on a fix and coordinated disclosure.
