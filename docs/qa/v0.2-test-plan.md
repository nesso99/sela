## Manual — grid editing (M2-1 / M2-3)

| ID | Steps | Expect |
| --- | --- | --- |
| M-01 | Open a table with a primary key; Enter on a text cell; type; Enter | Dirty triangle + gutter `•`; pending bar shows counts |
| M-02 | Ghost NULL on a text cell that was NULL, then clear and accept empty | Stores `''`, not NULL; triangle appears |
| M-03 | Esc with editor open after typing | Editor closes; ChangeSet unchanged |
| M-04 | Insert / Duplicate / Delete toolbar and shortcuts | `+` / `++` / `−` gutter; duplicate leaves PK unset |
| M-05 | Delete a dirty server row, then Delete again | Strikethrough then restore edits |
| M-06 | Preview → sheet 240px with bound params | Matches ChangePlan order (DELETE, UPDATE, INSERT) |
| M-07 | Discard (button or Ctrl/⌘+Shift+Z) → Cancel primary | Confirm; Cancel leaves edits; Discard clears |
| M-08 | Commit success | Bar closes; page reloads; status `Committed · N statements · …` |
| M-09 | Force ChangeConflict (edit PK of a row elsewhere, then Commit) | Rollback; edits kept; banner `No row matched …`; status `Commit failed · statement N of M · changes kept` |
| M-10 | Table without PK | Read-only strip; Insert/Duplicate/Delete disabled |
| M-11 | SQL result tab; Enter | Status: SQL results are read-only…; no strip |
| M-12 | Close tab / Quit with pending | Confirm; Cancel primary; Enter/Esc cancel |
| M-13 | Switch / Disconnect / Delete connection with pending edits | Confirm includes pending-changes sentence |
| M-14 | Edit an Insert / Duplicate overlay cell (Enter or double-click) | In-cell editor; context menu has Insert/Duplicate/Delete |
| M-15 | Commit while editing; try Insert or F5 during Committing… | Mutations/reload blocked until commit finishes |
| M-16 | Accept a cell without changing text | No dirty mark |
| M-ORG-01 | New connection: pick Red swatch; helper mentions Confirm writes; Safe mode shows Confirm writes | Swatch selected; form saves `color: red` and `safe_mode: confirm` |
| M-ORG-02 | Set label + group; save; sidebar shows muted label and group parent | Group expands; ungrouped stay above |
| M-ORG-03 | Duplicate a connection that has a keychain password | New row `{name} copy`; connect asks for password; original still connects |
| M-ORG-04 | Import URL `postgres://u:p@host:5432/db` then Save | Form fills; URL field clears; password masked; keychain gets secret on save |
| M-ORG-05 | Import bad scheme / missing host | Error line; other fields unchanged |
| M-FONT-01 | Status menu 11…18 and Reset; Cmd/Ctrl+= / − / 0 | Size persists across relaunch; theme switch keeps size |
| M-FONT-02 | At size 18, toolbar/status/tab heights unchanged | Text larger; chrome heights fixed |

## Manual — safe mode (M2-4)

| ID | Steps | Expect |
| --- | --- | --- |
| SM-01 | Open an existing connection saved before this build (no `safe_mode` field). | Loads. Toolbar shows `Safe: Off`. File still loads without migration. |
| SM-02 | Connection dialog → Safe mode → Confirm writes → Save. Reopen the file. | JSON has `"safe_mode": "confirm"`. Toolbar `Safe: Confirm`. Helper text under the select matches Confirm. |
| SM-03 | Set Safe mode to Off and save. | `safe_mode` omitted from JSON. Toolbar `Safe: Off`. |
| SM-04 | Set Read-only. Run `SELECT 1`. | Runs. No confirm. |
| SM-05 | Read-only. Run `UPDATE t SET a = 1 WHERE id = 1`. | Banner: `Read-only connection. The statement was not run.` Status: `Read-only · statement not run`. No history row. No result opened for that run. |
| SM-06 | Confirm writes. Run a write with WHERE. | Dialog `Run this write?`. Cancel primary; Enter and Esc cancel; nothing runs. Click **Run** → statement runs. |
| SM-07 | Off. Run `UPDATE t SET a = 1` (no WHERE). | Dialog `This statement has no WHERE`. Cancel cancels; **Run anyway** runs. |
| SM-08 | Confirm writes. Run `DELETE FROM t` (no WHERE). | No-WHERE dialog only (replaces confirm-writes). |
| SM-09 | Off. Run `UPDATE t SET a = 1 WHERE 1 = 1`. | Runs immediately (no no-WHERE dialog). |
| SM-10 | Any level except Read-only. Run unparseable SQL. | Parse dialog; Cancel / **Run anyway**. Read-only: refuse, no Run anyway. |
| SM-11 | Confirm writes. Run-all with a read then a write. | One confirm; body lists the write; mentions reads run only if you continue. Cancel runs nothing. |
| SM-12 | History Rerun of a write on Read-only. | Refusal (same copy as SM-05), not the old “Rerun this statement?” dialog. |
| SM-13 | History Rerun of `SELECT 1`. | Opens/runs without a safe-mode write dialog (existing read path). |
| SM-14 | Narrow the window so the endpoint is long. | Endpoint ellipsizes; `Safe: …` stays visible. |
| SM-15 | Confirm writes. Pending grid edits → Commit. | Dialog `Commit N changes?`; Cancel primary; **Commit** runs. |
| SM-16 | Off. Pending grid edits → Commit. | Sends immediately (no confirm). Never the no-WHERE dialog. |
| SM-17 | Read-only (after pending edits exist, or before). | Strip `Read-only · safe mode on this connection.`; Commit disabled; Discard still works; new cell edits refused. |
