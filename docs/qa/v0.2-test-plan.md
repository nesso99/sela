# v0.2 test plan

Manual and automated checks for M2 safe editing (grid overlay + preview/commit). Core ChangeSet / ChangePlan / `apply_changes` coverage lives in `sela-core` and `sela-drivers` unit/integration tests from M2-1/M2-2.

## Automated (run in CI / locally)

| ID | Check | How |
| --- | --- | --- |
| AE-01 | Dirty tracking, revert-to-original clears mark | `cargo test -p sela-app edit_session` |
| AE-02 | Insert / duplicate / delete overlay markers (`+`, `++`, delete-of-insert drops) | same |
| AE-03 | Delete preserves cell edits; undelete restores Dirty | same |
| AE-04 | Discard clears ChangeSet, overlay, preview, commit-failed flag | same |
| AE-05 | Failed commit keeps edits (`note_commit_failure`) | same |
| AE-06 | NULL vs `''` for text; empty non-text refuses | same |
| AE-07 | Commit blocked until non-generated PK set on insert | same |
| AE-08 | Preview sheet lists placeholders + bound values | same |
| AE-09 | ChangeConflict status names statement index | same |
| AE-10 | Esc / cancel editor leaves ChangeSet unchanged | same |
| AE-11 | No PK / view → read-only strip copy | same |
| AE-12 | Edits / insert / delete rejected while committing | same |
| AE-13 | Accepting an unchanged cell is a no-op | same |
| AE-14 | Editor keeps captured PK on accept | same |
| AE-15 | Parsing Time / Timestamp / Date / Uuid | same |
| AE-16 | Generated-column detection uses `ColumnStructure.generated` | same |
| AE-17 | Multi-line cell → `Use SQL to change it.` | same |
| AE-18 | ChangeConflict banner `No row matched …` + 1-based status | same |
| AC-01 | ChangeSet / ChangePlan / apply_changes (engines) | existing `sela-core` / `sela-drivers` tests |
| AC-02 | Postgres uuid PK + date/numeric/jsonb/timestamptz apply_changes | `cargo test -p sela-drivers postgres_apply_changes_uuid` (needs `SELA_POSTGRES_URL`) |
| AC-03 | Postgres typed bind casts in ChangePlan | `cargo test -p sela-core postgres_typed_binds_emit_casts` |
| AO-01 | Connection color/label/group serde defaults + round-trip; unknown color → none | `cargo test -p sela-core connection::` |
| AO-02 | URL import: postgres/mysql/sqlite schemes, percent-encoding, ports, missing parts, invalid | `cargo test -p sela-core connection_url` |
| AO-03 | Duplicate name sequence; duplicate copies fields but not password (no keychain write) | `cargo test -p sela-core connection_org` |
| AO-04 | Sidebar group ordering (ungrouped first, then first-appearance groups) | `cargo test -p sela-core connection_org` |
| AO-05 | Red → Confirm writes via `default_safety_level_for_color` | `cargo test -p sela-core connection_color` |
| AF-01 | Font size clamp 11–18; mono = max(11, ui−1); row/line formulas | `cargo test -p sela-config settings` |
| AF-02 | settings.json theme-only file defaults font_size 13; round-trip theme+font | same |

## Manual (UI)

| ID | Steps | Expect |
| --- | --- | --- |
| M-01 | Open a table with a primary key; Enter on a text cell; type; Enter | Dirty triangle + gutter `•`; pending bar shows counts |
| M-02 | Ghost NULL on a text cell that was NULL, then clear and accept empty | Stores `''`, not NULL; triangle appears |
| M-03 | Esc with editor open after typing | Editor closes; ChangeSet unchanged |
| M-04 | Insert / Duplicate / Delete toolbar and shortcuts | `+` / `++` / `−` gutter; duplicate leaves PK unset |
| M-05 | Delete a dirty server row, then Delete again | Strikethrough then restore edits |
| M-06 | Preview → sheet 240px with bound params | Matches ChangePlan order (DELETE, UPDATE, INSERT) |
| M-07 | Discard (button or Ctrl/⌘+Shift+Z) → Cancel primary | Confirm; Cancel leaves edits; Discard clears |
| M-08 | Commit success | Bar closes; page reloads; status `Committed · N statements · …` |
| M-09 | Force ChangeConflict (edit PK of a row elsewhere, then Commit) | Rollback; edits kept; banner `No row matched …`; status `Commit failed · statement N of M · changes kept` |
| M-10 | Table without PK | Read-only strip; Insert/Duplicate/Delete disabled |
| M-11 | SQL result tab; Enter | Status: SQL results are read-only…; no strip |
| M-12 | Close tab / Quit with pending | Confirm; Cancel primary; Enter/Esc cancel |
| M-13 | Switch / Disconnect / Delete connection with pending edits | Confirm includes pending-changes sentence |
| M-14 | Edit an Insert / Duplicate overlay cell (Enter or double-click) | In-cell editor; context menu has Insert/Duplicate/Delete |
| M-15 | Commit while editing; try Insert or F5 during Committing… | Mutations/reload blocked until commit finishes |
| M-16 | Accept a cell without changing text | No dirty mark |
| M-ORG-01 | New connection: pick Red swatch; helper mentions Confirm writes | Swatch selected; form saves `color: red` |
| M-ORG-02 | Set label + group; save; sidebar shows muted label and group parent | Group expands; ungrouped stay above |
| M-ORG-03 | Duplicate a connection that has a keychain password | New row `{name} copy`; connect asks for password; original still connects |
| M-ORG-04 | Import URL `postgres://u:p@host:5432/db` then Save | Form fills; URL field clears; password masked; keychain gets secret on save |
| M-ORG-05 | Import bad scheme / missing host | Error line; other fields unchanged |
| M-FONT-01 | Status menu 11…18 and Reset; Cmd/Ctrl+= / − / 0 | Size persists across relaunch; theme switch keeps size |
| M-FONT-02 | At size 18, toolbar/status/tab heights unchanged | Text larger; chrome heights fixed |
