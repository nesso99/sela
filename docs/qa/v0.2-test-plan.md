# Sela v0.2 test plan

Manual and automated checks for M2 safe-editing work. Extend this file as M2-1…M2-5 land. Automated coverage lives in crate unit tests; cases below are the interactive acceptance bar.

## M2-4 Safe mode

Automated: `cargo test -p sela-core --lib safe_mode`, connection serde tests, `cargo test -p sela-config safe_mode`, `cargo test -p sela-app safe_mode`.

| ID | Steps | Expect |
| --- | --- | --- |
| SM-01 | Open an existing connection saved before this build (no `safe_mode` field). | Loads. Toolbar shows `Safe: Off`. File still loads without migration. |
| SM-02 | Connection dialog → Safe mode → Confirm writes → Save. Reopen the file. | JSON has `"safe_mode": "confirm"`. Toolbar `Safe: Confirm`. Helper text under the select matches Confirm. |
| SM-03 | Set Safe mode to Off and save. | `safe_mode` omitted from JSON. Toolbar `Safe: Off`. |
| SM-04 | Set Read-only. Run `SELECT 1`. | Runs. No confirm. |
| SM-05 | Read-only. Run `UPDATE t SET a = 1 WHERE id = 1`. | Banner: `Read-only connection. The statement was not run.` Status: `Read-only · statement not run`. No history row. No result opened for that run. |
| SM-06 | Confirm writes. Run a write with WHERE. | Dialog `Run this write?`. Cancel primary; Enter and Esc cancel; nothing runs. Click **Run** → statement runs. |
| SM-07 | Off. Run `UPDATE t SET a = 1` (no WHERE). | Dialog `This statement has no WHERE`. Cancel cancels; **Run anyway** runs. |
| SM-08 | Confirm writes. Run `DELETE FROM t` (no WHERE). | No-WHERE dialog only (replaces confirm-writes). |
| SM-09 | Off. Run `UPDATE t SET a = 1 WHERE 1 = 1`. | Runs immediately (no no-WHERE dialog). |
| SM-10 | Any level except Read-only. Run unparseable SQL. | Parse dialog; Cancel / **Run anyway**. Read-only: refuse, no Run anyway. |
| SM-11 | Confirm writes. Run-all with a read then a write. | One confirm; body lists the write; mentions reads run only if you continue. Cancel runs nothing. |
| SM-12 | History Rerun of a write on Read-only. | Refusal (same copy as SM-05), not the old “Rerun this statement?” dialog. |
| SM-13 | History Rerun of `SELECT 1`. | Opens/runs without a safe-mode write dialog (existing read path). |
| SM-14 | Narrow the window so the endpoint is long. | Endpoint ellipsizes; `Safe: …` stays visible. |

### Out of scope for this milestone’s UI

- Red swatch auto-defaulting Confirm writes (M2-5 color UI).
- Grid Commit confirm / Read-only strip (M2-3 / M2-1 app). Core gate: `decide_grid_commit_gate`.
