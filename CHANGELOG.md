## [Unreleased]

### Added

- M3-4 command palette + quick open: Cmd/Ctrl+P opens table mode (fuzzy over the schema cache; Enter opens/focuses a Data tab); Cmd/Ctrl+Shift+P opens action mode (primary actions with keybindings; unavailable rows stay visible, dimmed, with a reason). Type `>` in table mode to switch to actions. Preview stays on Cmd/Ctrl+Shift+V (moved in #112) and does not fire while a text input has focus. Headless UI tests cover the palette surface and cancel pending-bar copy; see [12-command-palette.md](docs/design/ux/12-command-palette.md) and [v0.3-test-plan.md](docs/qa/v0.3-test-plan.md) (`PAL-*`).
- M3-1 SSH tunnel UI (US-02): connection dialog **Use SSH tunnel** block for Postgres/MySQL (absent for SQLite) — Host/Port/User, Auth (Private key default / Password / SSH agent), key Browse + passphrase, Import from `~/.ssh/config` host picker. Test / Save / Save & connect; success `Connected in {ms} ms (via SSH).` First-seen host key confirm (Cancel primary; Accept & save); changed host key hard-error dialog (no override). SSH secrets in keychain; Import URL never touches SSH; Duplicate copies host settings not secrets. Tunnel-drop banner `SSH tunnel closed. The connection was dropped.` Headless UI tests for SSH-05/07/08/14/16/18/19/20. User docs updated.
- M3-1 SSH tunnel (US-02): new `sela-ssh` crate (russh) with password, private key (+ passphrase), and ssh-agent auth; explicit Import from `~/.ssh/config` (Include one level; ProxyJump/ProxyCommand rejected); known_hosts match / hard mismatch / typed unknown-host challenge with fingerprint (caller confirms before write); injectable paths for tests. `SavedConnection.ssh` stores resolved fields (`private_key_path`; auth default Private key; no secrets in JSON; no schema bump). Drivers open the tunnel first and dial `127.0.0.1:<ephemeral>` while keeping the logical DB host for TLS SNI / verify-full; SQLite rejects enabled SSH. SSH passwords/passphrases use keychain accounts `{id}:ssh-password` / `{id}:ssh-passphrase` (`Debug` redacts secrets). New `DbError::Ssh` with `SSH:` error copy. Gated integration tests + `scripts/run-ssh-bastion.sh` / `ssh-integration` CI job.
- M3-3 export / CSV import core (US-12): streaming CSV, JSON (array or NDJSON), and batched SQL INSERT writers in `sela-core` that take an injectable `io::Write`, report row progress, and honour `CancellationToken`. JSON object keys follow column order; `NUMERIC` is an exact raw JSON number and JSON column text is emitted after validation with raw `\n`/`\r` collapsed to spaces (NDJSON-safe). SQL INSERT flushes at 100 rows or about 1 MiB of statement text, whichever comes first. CSV import streams from an injectable `io::Read` (buffered; strips a leading UTF-8 BOM), maps headers case-insensitively via `TableSchemaSource` (unmatched → Skip), reports per-row errors with line numbers (including invalid UTF-8), gates on safe mode, and feeds `ChangeSet` / `ImportRowSink`. Default CSV NULL is an **empty field** (optional `\N`; text equal to the sentinel is quoted); optional UTF-8 BOM off; exports use LF line endings. No UI in this change — see [export-import.md](docs/user/export-import.md), [11-export-import.md](docs/design/ux/11-export-import.md), and [v0.3-test-plan.md](docs/qa/v0.3-test-plan.md) (`EX-*` / `IM-*`).
- #68 `apply_changes` cancel + always-on optimistic WHERE: `DatabaseSession::apply_changes` takes a `CancellationToken` (Stop / `secondary-.` / pending-bar Cancel; status `Commit cancelled. No changes were saved.`). `UPDATE`/`DELETE` `WHERE` ANDs comparable previous non-PK values (`IS NULL` for NULL; skips `Other`, PG `json`, MySQL JSON, XML, geometric types, oversized blobs — Preview lists `-- unchecked optimistic:`). Conflict: `Row changed since it was loaded. No changes were saved. Refresh and try again.` with banner **Refresh** (OW-05). Preview chord is `secondary-shift-v`. Golden snapshots (OW-01), driver CAN-*/OW-* (including typed float/json/blob), headless UI tests. See [v0.3-test-plan.md](docs/qa/v0.3-test-plan.md) and [08-preview-commit.md](docs/design/ux/08-preview-commit.md).
- Headless GPUI UI tests for high-risk flows (#93): `gpui_kit::TestAppContext` harness in `crates/sela-app/src/ui/ui_tests/`, run with `./scripts/ui-tests.sh` (Xvfb optional on Linux). Covers connection-dialog Enter/Save/Cancel and password masking, cell-editor Space / empty accept / Duplicate+Copy as INSERT, and table-tab reload after SQL on Save/reconnect and on plain tab switch (#98).
- `wgpu` is pinned to `=30.0.1` (was 30.0.2) so the GPUI test-support build resolves; the shared lockfile means the release binary also uses wgpu 30.0.1. Rendering should be re-checked on X11.

### Fixed

- After a cancelled commit, the pending bar shows `Commit cancelled. No changes were saved.` instead of `Commit failed. Changes kept.` (CAN-03 / #112 follow-up).
- Preview (`secondary-shift-v`) does not run while a text input has focus, so paste still works (#112 follow-up).
- After Save/reconnect, a table tab that last ran SQL reloads the table instead of keeping the stale SQL grid under the table title (#98). The same reload runs on every tab switch while the grid still holds a SQL result in a table tab, so that SQL result is dropped when leaving and returning to the tab.
- Commit success status `Committed · N statements · … ms` survives the post-commit page reload: `load_source_for` no longer clears `post_commit_reload` or overwrites the line with `Running…` before the reload finishes (#81).
- Status `ms` after Structure → Data (and other idle refreshes) uses the last completed query duration, not wall time since the load started (#95).
- Copy of an Insert/Duplicate overlay row with unset cells (e.g. unset PK) succeeds and omits those cells; it no longer reports `rows not loaded yet` (#99).
- Enter in the Import URL field fills the form and keeps the New/Edit connection dialog open; it no longer dismisses via the dialog Confirm path (#96).
- Duplicate of a SQLite (or any no-password) connection leaves `needs_password` false and connects without opening Edit (#97).
- A failed Import URL clears the previous `Filled from the URL…` success line; a later success clears the error line (#100).
- Linux/Windows SSD File menu row uses `h_flex` so the File trigger is content-sized and left-aligned; the DropdownMenu opens under File instead of at the window top-left over the sidebar title (#101).
- Space inspect popover anchors to the focused cell instead of the results-area top-left (#102).
- Status bar restores the Data row-count line when switching Structure → Data (#75); does not overwrite a `Query failed` status.
- Cell editor ghost NULL control at the right edge of the inline editor (#76).
- Accepting an empty text editor opened on NULL stores `''` and marks the cell dirty; empty accept on an unset insert cell leaves the column out so DEFAULT applies (#77).
- Space opens the cell inspect popover (column, type, full `Value::display()`); Space inside the cell editor inserts a space character (`NoAction` in the `CellEditor` context) (#78).
- Duplicate overlay inserts directly under the source row, keyed by source primary key so paging/filtering never drops it; copy/select/touch use visual row indices (#79). Overlay copy keeps typed `Value`s (NULL/Int/`''`/unset) instead of display strings, so Copy as INSERT/JSON stay correct.
- Dirty-triangle and gutter-mark tooltips (`Edited · was …`, `Edited row`, `New row`, `Duplicated row`, `Deleted row`) (#80).
- Inspect popover closes on selection change, edit, reload, commit, or pane switch; unset cells show `Unset` instead of `…`.
- Enter in the Import URL field no longer panics with a re-entrant `ConnectionForm` update; the subscription calls import on the form already being updated (#84).
- Enter on a safe-mode confirm (`Run this write?` and related) cancels like the quit dialog and does not type into the SQL editor (#83).
- Connection password field is masked by default, including after Import URL (#85).
- Connecting a Duplicate opens the password dialog (`needs_password` on the copy). Saved empty-password / trust connections still connect after restart without prompting (#87).
- Read-only Safe mode helper matches the connection-dialog spec: `Writes are refused. Reads run as usual.` (#82).
- Import URL reports `The URL has no host.` for an empty host and `Port must be a number from 1 to 65535.` for an out-of-range port (#86).
- Duplicate status `Duplicated {name}. Type the password to connect.` is shown when no tab is open (#88).
- Sidebar footer wraps so **Disconnect** stays readable at font size 18 (#89).

## [0.2.0] - 2026-11-25

### Added

- M2-5 connection organization: named color swatches (light/dark pairs; Red = production), optional label and one-level sidebar groups, Duplicate (copies settings but not the password / keychain secret), and Import URL for `postgres://` / `mysql://` / `sqlite:` (password goes to the keychain path on save; URLs are never logged). Config fields default so v0.1 files still load. On a new connection, choosing Red sets Safe mode to Confirm writes until the user touches that control.
- User-adjustable font size (#39): one UI step 11–18 (default 13) in `settings.json`; mono is `max(11, ui − 1)`; chrome heights stay fixed. Status-bar size menu plus Ctrl/⌘+= (also Shift+= / +) / − / 0. Old theme-only settings files keep loading.
- M2-4 safe mode: per-connection Off / Confirm writes / Read-only (`safe_mode` on `connections.json`, missing = Off, no schema migration). Toolbar shows `Safe: …`. The SQL editor, history Rerun, and grid Commit classify / gate with `sqlparser` and `decide_*_gate`: writes confirm or refuse; `UPDATE`/`DELETE` without `WHERE` always warn (editor); unparseable SQL fails closed. Confirms reuse the quit dialog pattern (Cancel primary; Enter/Esc cancel). Read-only also sets a server-side guard (Postgres `default_transaction_read_only`, MySQL `SESSION TRANSACTION READ ONLY`, SQLite `read_only`); saving the connection reconnects so the level applies immediately. See [safe-mode.md](docs/user/safe-mode.md).
- M2-1 / M2-3 grid editing UI: primary-key tables only (no-PK / views / SQL results are read-only with the specified strip or status); in-cell editor (Enter / double-click; Esc cancels the editor only); NULL ghost control vs empty text `''`; dirty triangles and gutter marks (`•` / `+` / `++` / `−`); Insert / Duplicate / Delete on the Data toolbar and context menu; 26px pending bar; Preview SQL sheet from `ChangePlan` (placeholders + bound values); Commit via `apply_changes` (failed commit keeps edits, no reload); Discard with quit-style confirm (Cancel primary). Unit tests for dirty tracking, markers, discard, and failed-commit retention; QA checklist in [docs/qa/v0.2-test-plan.md](docs/qa/v0.2-test-plan.md).
- Linux client-side title bar when the compositor requires CSD (e.g. GNOME Wayland): gpui-component `TitleBar` with app title, File menu, minimize / maximize / close, drag-to-move, and double-click maximize/restore. Shown only when `window.window_decorations()` is `Decorations::Client`; Windows, macOS, and SSD Linux (X11 / KDE) stay on the native title bar. Close uses the same quit path as Ctrl+Q. CSD resize edges and shadow come from gpui-component’s existing `window_border()` RootPlugin wrap (not new Sela code). Right-click on the title bar does not open the platform window menu (#58).
- M2-1 / M2-2 safe-editing core (no UI): `ChangeSet` records pending cell updates, inserts, and deletes for tables with a primary key (merge rules for insert-edit, insert-delete, and revert-to-original); `ChangePlan` builds ordered DELETE → UPDATE → INSERT SQL for PostgreSQL, MySQL, and SQLite with dialect quoting and bind parameters only; `ChangePlan::preview_sql` / `preview_bound` for the upcoming preview dialog; `DatabaseSession::apply_changes` runs a plan in one transaction on all three engines. Each UPDATE/DELETE must affect exactly one row (`DbError::ChangeConflict` otherwise, full rollback). MySQL connections keep `CLIENT_FOUND_ROWS` so same-value UPDATEs still count as matched. Golden SQL snapshots and driver integration tests included. No schema-migration code.
- UX specs for v0.2 safe editing: grid editing, preview and commit, safe mode ([docs/design/ux/07-grid-editing.md](docs/design/ux/07-grid-editing.md), [08](docs/design/ux/08-preview-commit.md), [09](docs/design/ux/09-safe-mode.md)), connection color, groups, duplicate, and import URL, font size (#39), and the Linux client-side title bar. Editing is primary-key only (a unique NOT NULL key is an M2 follow-up on the roadmap). The title bar matches gpui-component `TitleBar` as built in #66 (34px, File menu inside the bar, close through `request_quit`). Indexed in [docs/design/ux/README.md](docs/design/ux/README.md).

### Fixed

- Safe-mode classifier: `EXPLAIN (ANALYZE …)` (paren options), `SELECT … INTO`, and `SELECT … FOR UPDATE`/`FOR SHARE` are writes; MySQL `/*!50000 DELETE … */` is a no-WHERE DELETE; unparsed forms (`DO`, `LOAD DATA`, `INTO OUTFILE`, smuggled multi-statement comments) fail closed. Batch no-WHERE / parse-failed dialogs note other writes in the batch. History Rerun at Off still asks “Rerun this statement?” for writes (v0.1 path via `decide_history_rerun`).
- Grid editing review follow-ups: block mutations and page reload/sort/filter/paging/catalog refresh while Commit is in flight (own spawn + commit generation); capture PK/old value in the cell editor; unchanged accept is a no-op; multi-line cells stay read-only (`Use SQL to change it.`); typed Time/Timestamp parse; Postgres `$n::type` casts for uuid/date/numeric/json(b)/timestamptz/interval; edit Insert/Duplicate overlay rows (double-click + editor); keep dirty ChangeSet when `describe_table` fails; `ColumnStructure.generated` from drivers (identity / EXTRA / table_xinfo); ChangeConflict banner `No row matched {schema.table} for this key.` with 1-based statement status; post-commit reload failure status `Committed · the page failed to reload.`; confirm pending edits on Switch / Disconnect / Delete connection.
- Result grid range selection: Shift+click and Shift+arrow extend `selection_rect` (highlighted), Ctrl/Cmd+A selects all cells, and right-click inside a range still keeps the range for Copy (#59).
- Result grid keyboard selection: Shift+arrow binds explicitly in the `DataTable` context (DataTable only handles plain arrows), and Ctrl/Cmd+A no longer collapses after a deferred `SelectCell` from `set_selected_cell` (#59).
- SQLite: expression column headers show the runtime storage class (INTEGER / REAL / TEXT / BLOB) of the first non-NULL value, or no type when unknown / all NULL — never `NULL` as a type (#60).
- SQL / result toolbar page label uses the real row count and page (`Page N · {n} rows` or `Page N of M`), not a hardcoded `Page 1 · 100 rows` (#61).
- Postgres `void` (e.g. `SELECT pg_sleep(n)`) renders as a NULL-style cell with header type `void`, not a red `!<VOID>` decode marker (#62).
- Saved passwords persist again: enable keyring v3 platform stores (`apple-native`, `windows-native`, `sync-secret-service` + `crypto-rust`) instead of the in-process mock; startup and tests fail loudly if the mock is still the default. When the OS keychain is unavailable at runtime, the #46 memory-only warning still applies (#51).
- Connection error banner clears when connecting, switching connection, disconnecting, or after a successful connect, so a failed MySQL/Postgres auth message is not left over a working session (#52).
- Stop / cancel: replace a stale grid `Running…` empty message with `Query cancelled.` when no rows were delivered (same pattern as failed-query empty state) (#53).
- SQLite: expression columns with no declared type (e.g. `SELECT 42`, `'a' || 'b'`, blobs) decode from the value’s runtime storage class instead of showing SQL NULL (#54).
- Result grid right-click context menu: Copy and Copy as TSV / CSV / JSON / INSERT on cells (TC-COPY-01); cell selection no longer swallows the menu (#55).
- Right-click Copy: select the clicked cell first when it is outside the current selection (or when nothing is selected), so Copy never targets a different cell or an empty selection; a right-click inside a range keeps the range (Refs #55).
- Switching saved connections while one is active cancels and closes the previous connection’s tabs, then connects the chosen row; Edit targets the tree selection instead of only the live session. If those tabs have typed SQL or a busy query, Switch asks first (Cancel keeps the current session) (#45).
- When the OS keychain / Secret Service is unavailable, the connection dialog and status bar warn that the password is kept for this session only and will not be saved after quit; in-memory passwords still work for connect, reconnect, and switch (#46).
- Disconnect cancels running queries for the active connection and closes that connection’s tabs (persisting `tabs.json`) so stale tabs are not left open or restored for the wrong database. Typed SQL or a busy query prompts before close; Cancel leaves the session unchanged (#48).
- SQL editor results: drain buffered stream batches when the producer finishes first, so the grid shows rows instead of blank stripes while the status bar already reports a row count (#44).
- Table Previous/Next: install the fetched page at row 0 (pager model) instead of an absolute `page_offset` index, so page 2+ shows the new rows rather than placeholders or page-1 data (#42).
- Failed queries: replace a stale grid `Running…` empty message with `Query failed — see the error above.`; record streamed SQL statements in query history with the full statement text (#47).

## [0.1.0] - 2026-11-24

### Fixed

- Query history: MySQL `IDENTIFIED WITH <plugin> BY` (including `caching_sha2_password` and `mysql_native_password`) is skipped like other password-setting DDL, instead of being stored in `history.sqlite` (#32).
- Filter `LIKE` / `NOT LIKE`: pass the user's pattern through with `ESCAPE '!'` so `!%`, `!_`, and `!!` match literal `%`, `_`, and `!` (dangling `!` becomes `!!`). Legacy contains/starts/ends still fully escape. (#33)
- Copy as INSERT: non-finite floats (`NaN` / ±Infinity) are quoted for Postgres (`'NaN'`, `'Infinity'`, `'-Infinity'`) and refused on MySQL/SQLite with a status message naming the column. JSON copy emits a JSON string for those values (valid JSON; not a bare `NaN` token). Roadmap/SPECS M1-3 and M1-7 status markers updated to Done (#17/#22, #24).

Artifacts: Linux `tar.gz` + AppImage, macOS Apple Silicon (arm64) `.dmg` + `.zip` (unsigned; **Intel Macs are not supported yet**), Windows `.zip`, plus `SHA256SUMS` and notes from this changelog section.
